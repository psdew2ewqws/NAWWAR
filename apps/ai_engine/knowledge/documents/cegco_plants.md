# CEGCO Power Plants — Specifications
# محطات شركة توليد الكهرباء المركزية — المواصفات الفنية

> **Central Electricity Generating Company (CEGCO)**
> شركة توليد الكهرباء المركزية
>
> **Ownership / الملكية**: 51% ACWA Power (Saudi Arabia) — 49% Government of Jordan
>
> **Total Installed Capacity / القدرة الإجمالية المركّبة**: ~1,555 MW

## 1. Aqaba Thermal Power Station / محطة العقبة الحرارية

| Parameter / المعامل | Value / القيمة |
|:--|:--|
| **Location / الموقع** | Aqaba, southern Jordan / العقبة، جنوب الأردن |
| **Coordinates / الإحداثيات** | 29.5167°N, 35.0000°E |
| **Installed Capacity / القدرة المركّبة** | 390 MW |
| **Number of Units / عدد الوحدات** | 5 steam turbines / ٥ توربينات بخارية |
| **Unit Capacity / قدرة الوحدة** | Unit 1-4: 66 MW each, Unit 5: 126 MW |
| **Technology / التقنية** | Conventional Steam (Rankine cycle) / بخاري تقليدي |
| **Fuel / الوقود** | Multi-fuel: Heavy Fuel Oil (HFO) & Natural Gas / متعدد الوقود: زيت ثقيل وغاز طبيعي |
| **Commissioned / سنة التشغيل** | 1985-1987 |
| **Cooling / التبريد** | Once-through seawater cooling (Red Sea) / تبريد بمياه البحر (البحر الأحمر) |
| **Status / الحالة** | Operational / تعمل |

### Technical Details / التفاصيل الفنية:
- Steam conditions: 130 bar, 540°C superheat / ظروف البخار: ١٣٠ بار، ٥٤٠°م
- Heat rate: ~10,500 kJ/kWh / معدل الحرارة: ~١٠,٥٠٠ كج/كوس
- Annual generation: ~2,400 GWh / التوليد السنوي: ~٢,٤٠٠ جيجاواط ساعة
- Availability factor: ~85% / عامل التوفّر: ~٨٥٪
- Connected to the national grid via 132 kV double-circuit lines.
- متصلة بالشبكة الوطنية عبر خطوط ١٣٢ ك.ف مزدوجة الدارة.

## 2. Risha Gas Power Station / محطة الريشة الغازية

| Parameter / المعامل | Value / القيمة |
|:--|:--|
| **Location / الموقع** | Risha, eastern desert / الريشة، الصحراء الشرقية |
| **Coordinates / الإحداثيات** | 32.2500°N, 38.2500°E |
| **Installed Capacity / القدرة المركّبة** | 150 MW |
| **Number of Units / عدد الوحدات** | 4 gas turbines / ٤ توربينات غازية |
| **Unit Capacity / قدرة الوحدة** | 37.5 MW each / ٣٧.٥ ميغاواط لكل وحدة |
| **Technology / التقنية** | Open Cycle Gas Turbine (OCGT) / دارة مفتوحة |
| **Fuel / الوقود** | Domestic natural gas (Risha gas field) / غاز طبيعي محلي (حقل الريشة) |
| **Commissioned / سنة التشغيل** | 1989-1994 |
| **Status / الحالة** | Operational / تعمل |

### Technical Details / التفاصيل الفنية:
- Gas supply from the adjacent Risha gas field (Jordan's only domestic gas source).
- التغذية بالغاز من حقل الريشة المجاور (المصدر المحلي الوحيد للغاز في الأردن).
- Heat rate: ~12,000 kJ/kWh (lower efficiency — open cycle).
- معدل الحرارة: ~١٢,٠٠٠ كج/كوس (كفاءة أقل — دارة مفتوحة).
- Primarily used for peak shaving and reserve capacity.
- تُستخدم أساساً لتغطية الذروة والاحتياطي.
- Annual generation: ~800 GWh / التوليد السنوي: ~٨٠٠ جيجاواط ساعة
- Risha gas field produces ~30 MMSCFD (variable).
- حقل الريشة ينتج ~٣٠ مليون قدم³/يوم (متغير).

## 3. Rehab Combined Cycle Power Station / محطة رحاب للدارة المركّبة

| Parameter / المعامل | Value / القيمة |
|:--|:--|
| **Location / الموقع** | Rehab, Mafraq Governorate / رحاب، محافظة المفرق |
| **Coordinates / الإحداثيات** | 32.3000°N, 36.1000°E |
| **Installed Capacity / القدرة المركّبة** | 297 MW |
| **Number of Units / عدد الوحدات** | 4 gas turbines + 2 steam turbines (CCGT) / ٤ غازية + ٢ بخارية |
| **Technology / التقنية** | Combined Cycle Gas Turbine (CCGT) / دارة مركّبة |
| **Fuel / الوقود** | Natural gas (imported via Arab Gas Pipeline) / غاز طبيعي (مستورد) |
| **Commissioned / سنة التشغيل** | 1990-1995 |
| **Status / الحالة** | Operational / تعمل |

### Technical Details / التفاصيل الفنية:
- Combined cycle efficiency: ~48-52% / كفاءة الدارة المركّبة: ~٤٨-٥٢٪
- Heat rate: ~7,500 kJ/kWh / معدل الحرارة: ~٧,٥٠٠ كج/كوس
- Gas turbines: GE Frame 9E class / توربينات غازية: فئة GE Frame 9E
- Steam turbines recover waste heat from GT exhaust via HRSG (Heat Recovery Steam Generator).
- التوربينات البخارية تسترجع حرارة العادم عبر مراجل استرجاع الحرارة (HRSG).
- Annual generation: ~1,800 GWh / التوليد السنوي: ~١,٨٠٠ جيجاواط ساعة
- Availability factor: ~88% / عامل التوفّر: ~٨٨٪

## 4. Al-Hussein Thermal Power Station / محطة الحسين الحرارية

| Parameter / المعامل | Value / القيمة |
|:--|:--|
| **Location / الموقع** | Zarqa, central Jordan / الزرقاء، وسط الأردن |
| **Installed Capacity / القدرة المركّبة** | 396 MW |
| **Number of Units / عدد الوحدات** | Mixed gas and steam turbines / خليط غازية وبخارية |
| **Technology / التقنية** | Gas Turbines + Steam (partial CCGT) / غازية + بخارية |
| **Fuel / الوقود** | Natural gas, Diesel / غاز طبيعي، ديزل |
| **Commissioned / سنة التشغيل** | 1975-1995 (various units) |
| **Status / الحالة** | Partially operational (some units decommissioned) / تعمل جزئياً |

### Technical Details / التفاصيل الفنية:
- Oldest CEGCO station; some units past their economic life.
- أقدم محطات CEGCO؛ بعض الوحدات تجاوزت عمرها الاقتصادي.
- Gas turbine units: 4 × 33 MW GE Frame 6.
- Steam turbine units: 2 × 66 MW + 1 × 132 MW.
